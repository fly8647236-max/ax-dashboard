# 장금상선 AX 대시보드

조원 9명이 각자 만든 에이전트의 결과 파일(json)을 한 화면에 모으는 조 대시보드입니다.

- 배포 링크: https://ax-dashboard-eosin.vercel.app
- `index.html` : AX 대시보드
- `slides.html` : 조별 발표 자료 (←/→ 넘기기, N 발표 메모)
- `roles.txt` : 역할 분담 메모

## 결과 파일 공통 형식
```json
{ "날짜": "2026-10-16", "처리건수": 12, "확인필요": 2, "아낀시간분": 15 }
```
