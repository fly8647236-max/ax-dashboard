조 역할 분담 메모
작성일: 2026-10-15
근거: 조원 9명의 "내 병목" PDF

원칙
- 9명 모두 자기 병목을 줄일 에이전트 1개씩 만든다.
- 비슷한 일끼리 2명씩 묶고, (확인) 표시한 사람이 짝의 결과를 확인한다.
- 모든 결과 파일(json)에는 공통 4칸을 똑같이 넣는다.
  날짜 · 처리 건수 · 확인 필요 건수 · 아낀 시간(분)

==================================================
① 오더 읽기
==================================================
박동환 (조장 가정)
  - 맡은 일: 오더 접수 정리
  - 만들 것: 메일·카톡 오더 → 구글 시트 자동 기입
  - 추가 역할: 공통 결과 파일 틀 · 대시보드 뼈대
  - 결과 파일: order.json

김지영 (확인)
  - 맡은 일: 배차판 정리·검사
  - 만들 것: 지시서(PDF·메일·카톡·네이트온) → 배차판 19칸 + [확인 필요] 목록
  - 추가 역할: 공통 「오더 읽기·검사」 스킬 제공 (이미 만들어 정답 3건 확인)
  - 결과 파일: dispatch.json

==================================================
② 금액 판단
==================================================
박혜진
  - 맡은 일: 배차 가능 판단
  - 만들 것: 이메일 오더 → 청구가·지급가 계산 → 마진 판정
  - 결과 파일: margin.json

김규리 (확인)
  - 맡은 일: KYSS 등록
  - 만들 것: 오더장 → 확실한 건은 등록, 애매한 건은 확인 필요 목록
  - 결과 파일: kyss.json

==================================================
③ 두 파일 대조
==================================================
차하정
  - 맡은 일: 재고 대사
  - 만들 것: 게이트로그·이트랜스·스탁파일 대사, 리즈벤 후보 찾기, SOUND 검산
  - 결과 파일: inventory.json

정한희 (확인)
  - 맡은 일: 해외정산 대조
  - 만들 것: 거래처 정산서와 프로그램 정산 내역 대조 (일치·금액 차이·누락·중복)
  - 추가 역할: 공통 「두 파일 대조」 스킬 제공
  - 결과 파일: settlement.json

==================================================
④ 조회·점검
==================================================
김정희
  - 맡은 일: 모선 스케줄 점검
  - 만들 것: 모선 10척 ETA·ETD 변동 건 → 화주 메일 초안
  - 추가 역할: 매일 자동 실행 담당
  - 결과 파일: schedule.json

송민희 (확인)
  - 맡은 일: 서류·반입제한 확인
  - 만들 것: 오더별 서류 체크리스트(✅❌·반입제한) + 하루 현황 엑셀
  - 결과 파일: docs.json

==================================================
⑤ 실적 보고
==================================================
류민호
  - 맡은 일: 영업1팀 월간 실적 분석
  - 만들 것: 통합본 → 전월 대비 증감 · 신규·유지율 분석
  - 추가 역할: 대시보드 화면 · 보고용 요약
  - 결과 파일: sales.json
  - 참고: 김규리의 KYSS 등록이 실적의 원본이라 바로 이어짐
